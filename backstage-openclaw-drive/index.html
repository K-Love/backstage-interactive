Backstage OpenClaw Drive

Effective date: November 11, 2026. This page describes the private tool. It is not the privacy policy for the public website.

Backstage OpenClaw Drive is the name of an OAuth app. I, Kevin Love, operate that app as Backstage Interactive. It is a private tool for my own use. It is not a service offered to the public on this website.

Operating this app does not mean I operate OpenClaw in general. OpenClaw is the software the tool runs. I am not its general operator.

Purpose and scope

The public website at backstageinteractive.com has its own Privacy Policy and Terms of Use. Those pages cover the studio site and its contact forms. The forms ask for a note, a website-review request, or a Google Business Profile audit. They do not ask anyone to sign in with Google, and they do not request Google Drive.

This page describes a different thing: a private tool, on a Google account I use for it, with the connector aimed at a Drive folder I named. A person sending the homepage form is not using this tool, and this tool is not how the website stores form messages.

What is in place

These are the practices for this tool.

  • OpenClaw runs on a DigitalOcean server. Daily backups are enabled. The documented standard for that daily plan is seven days of rolling retention. That figure comes from DigitalOcean’s documents, not from a fresh audit of this account’s expiry setting. A full-server image is not edited to remove one file. Restoring a backup has not been tested.
  • The Google app is in Testing mode, not a production publishing status. A dedicated account authorized Drive with the scope https://www.googleapis.com/auth/drive. That scope can view, create, edit, and delete Drive files the account can access.
  • The connector is set to a folder named Backstage Work. That limit is in the connector configuration. Google does not enforce it as the boundary of the scope.
  • One test used a 171-byte file. The upload, the download, and a byte-for-byte comparison passed. The file remains in Deliverables and belongs to the dedicated automation account. That is one test, not routine automation.
  • The tested function transfers owner-selected files between Backstage Work and the private server. It accesses file contents and relevant metadata. The connection test did not send the test file to an AI model or Telegram. Routine exchange and AI analysis remain disabled.

Not current

Routine Drive exchange is not enabled. Chief integration is not enabled. A rule for removing transfer and staging copies is written for if that exchange is turned on. It is a future requirement, not an active workflow, and not a build schedule.

Retention, training, and Limited Use

I adopted a retention and deletion policy on November 7, 2026. Saved work stays until I delete it or set an expiry. Other copies follow manual targets. Automatic cleanup is not fully implemented, and adopting the policy deleted nothing. The schedule is in the privacy policy.

Revoking the Google authorization ends that authorized access. It does not erase copies already downloaded. Deleting the active credential file does not remove credentials that remain in older backups.

I do not use Google Drive data to train AI models. Abacus.AI publishes no-training commitments, but its own API retention and deletion deadlines remain unconfirmed. Future AI analysis requires a separate disclosure and consent before activation; see data use, recipients and provider limits.

Backstage OpenClaw Drive's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy (opens in a new tab), including the Limited Use requirements.
